# PeVeRaL

Game server developer. I build and run **World of Darkness roleplay servers**.

### Projects
- **WoD-RedM** *(private, in development)* — the next generation of World of Darkness roleplay, built from scratch for **RedM**: fully dynamic character sheets, every supernatural race with its powers, deep roleplay systems and a complete in-game admin platform.
- **Wraithfield RP** *(private, live)* — a long-running, fully developed World of Darkness roleplay server on **SA-MP**, still receiving regular updates and new features: a fully dynamic character sheet with races built in game, living NPCs (police, bodyguards, herds and hunts), factions and law, dynamic businesses, housing, vehicle crime, fishing, custom skins added live without a restart (including personal skins only their owner can wear), an in-game music player (play any YouTube song, saved playlists, music zones, boomboxes and car radios), storyteller tools and a staff web panel with live monitoring.

### Tools
Lua · Pawn · JavaScript / React · MySQL / MariaDB · Linux servers
